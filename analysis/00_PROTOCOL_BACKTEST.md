## 2. 적대적 테스트 — 규약을 통과하면서 나쁜 짓 하기 `[실측]`

논증이 아니라 **실제로 뚫어 본** 결과다. 1라운드에서 4개가 뚫렸다.

| 공격 | 1라운드 | 막은 방법 | 현재 |
|------|:------:|-----------|:----:|
| 예측 크기를 `최소 0%p` 로 | **뚫림** | `ZERO_MAG_RE` — 0은 예측이 아니다 | 막힘 |
| `MC 200회` 의 200을 크기로 오인시키기 | **뚫림** | 크기 단위에서 표본수(`회`) 제외 | 막힘 |
| 노이즈 이하 예측(`최소 2%p`, 시드 산포 ±4.0%p) | **뚫림** | 고정 seed 결정론 대조 또는 표본수+산포 명시 의무 | 막힘 |
| 판정 문자열 위조(`재현: chk_추후에만들것`) | **뚫림** | `chk_` 가 감사 도구에 **실제 정의**돼 있는지 대조 | 막힘 |
| 없는 프로브 경로만 적기 | 뚫림 | 파일 존재 확인 | 막힘 |
| 예측을 **코드 뒤에** 끼워넣기 | 뚫림 | 도입 커밋이 코드 커밋의 **조상**인지 `merge-base` 로 확인 | 막힘 |
| 예측을 사후에 **고쳐 쓰기** | 뚫림 | 같은 조상 검사에 걸린다(고친 문자열의 도입 커밋이 뒤가 됨) | 막힘 |
| 대장에 안 올리고 그냥 고치기 | 뚫림 | B판 안에서 선언 없는 코드 변경은 FAIL(반경 E/C/W/U/B) | 막힘 |
| 규약 검사를 **안 돌리기** | 뚫림 | `pre-commit` 훅에 배선(0.27초). B판 밖에서는 자동 생략 | 막힘 |
| `짝: 없음` · `무대: 아무거나` 로 형식만 채우기 | 뚫림 | — | **남음**(아래 4절) |

자기검증 **25항목**(A 11 + B 14) 전부 PASS — 케이스는 전부 위에서 실제로 뚫렸던 것이다.

## 3. 이 대조로 새로 굳힌 것

1. **`chk_global_name_import`** (`audit_static_scan.py`, 정적 54→56항목)
   — 재할당 전역(`global X`)을 `from mod import X` 하는 것을 금지. 과거 실제 결함 형태
   (`from app_utils import _GLOBAL_POOL`)를 주입해 **FAIL로 잡히는 것을 확인**하고 복구했다 `[실측]`.
   이 저장소가 **두 번 당하고도** `CLAUDE.md`의 "옮기기 전에 grep 하라"는 **사람 규칙으로만**
   남아 있던 자리다.
2. **`짝:`·`무대:` 필수 필드** — 발현 증거 3종 중 내가 빠뜨렸던 둘을 대장에 되살렸다.
3. **판정의 실재·선행성 검사** — 적어만 두고 안 만드는 것, 사후에 끼워넣는 것을 차단.
4. **훅 배선** — 규약이 "돌리기로 한 것"에서 "안 돌리면 커밋이 안 되는 것"이 됐다.

## 4. 이 대조 뒤에도 남는 것 (정직하게)

- **내용 판단은 기계가 못 한다.** `짝: 없음`·`무대: 적정 편성`·무관한 URL은 형식을 통과한다.
  4번 사건이 ⚠인 이유다. 완화책은 무대에 **수치가 없으면 경고**하는 것뿐이다.
- **R의 예측을 내가 쓴다** — 맞히기 쉬운 예측만 고르는 편향은 기계 밖이다.
- **반경 표 stale** — 새 파일은 미분류 FAIL로 *새는 것*만 막는다. 분류의 타당성은 사람이 본다.
- **pre-push 비용 `[미확인]`** — 첫 묶음에서 측정해 9.5를 갱신할 것.
- **`--no-verify`** 로 훅을 건너뛰는 것은 의도적 회피라 규약 범위 밖이다.
