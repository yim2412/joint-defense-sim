# 개발 노트

만들면서 **무엇이 어떻게 깨졌고 어떻게 알아냈는지**를 적은 글들이다.
기능 소개가 아니라 판단 기록이라, *"이건 아직 안 쟀다"* 도 그대로 적는다.

각 노트 끝에 커밋이 걸려 있다 — 주장이 아니라 **확인 가능한 것**으로 두기 위해서다.
수치는 `실측`(지금 다시 잼)과 `인용`(그때 그렇게 적혀 있음)을 구분해 표기한다.

## 합동 통합방어 시뮬레이터

한국 해군 이지스 기동전단의 다층 방어 시뮬레이터. 대공·대함·대잠 교전, 몬테카를로
분석, 요구조건 판정, 보고서 생성. Python + PyQt6, PyInstaller 로 배포한다.
전술 교전에서 시작해 작전급 캠페인 → 공군 → 육군 → 합동 화력으로 층이 쌓였다.

| 노트 | 무엇에 관한 글인가 |
|---|---|
| [「아무것도 안 깨졌다」만 보는 관문](01-a-gate-that-only-checked-nothing-broke.md) | **완료의 정의** — 하위 호환 검사는 아무 일도 안 하는 코드를 가장 쉽게 통과시킨다 |
| [적이 없어서 0이었다](02-there-was-no-enemy-so-it-was-zero.md) | **측정 설계** — "이 기능은 죽었다"는 판정이 두 번 다 내 측정 결함이었다 |
| [아무것도 안 보면서 통과한 검사들](03-checks-that-passed-while-looking-at-nothing.md) | **검증 사각** — 검사가 눈이 머는 네 가지 방식 |

후보는 [`CANDIDATES.md`](CANDIDATES.md) 에 29건이 정리돼 있다. 위 셋은 거기서 골랐고,
**탈락시킨 것과 그 이유**도 같이 남겨 뒀다.

### 이 프로젝트에서 쓰는 검증 장치

| 장치 | 무엇을 잡나 | 무엇을 못 잡나 |
|---|---|---|
| `audit_verify_regression.py` | 고정 시드 38케이스×29지표를 골든과 대조 — **의도치 않은 동작 변화** | 골든 자체가 틀렸을 때 · **골든이 안 밟는 경로** |
| `audit_static_scan.py` | 정적 51항목 — 3종세트·복원·버전·문서 정합 · 죽은 토글 커밋 게이트 | 런타임 동작 · **import 누락과 NameError는 전부 PASS 시킨다** |
| `audit_property.py` | 독립 불변식 — 확률범위·합=1·NaN/Inf·요격≤총 | 값이 "그럴듯하나 틀린" 경우 |
| `audit_effect.py` | 토글 ON/OFF 델타 — **이 기능이 무언가 하는가** | 짝 기능·무대가 없는 조건에서의 발현 |
| `audit_dead_toggle.py` | 전 토글 전수 스캔 + 발동 카운터 — 델타 0 의 원인 구분 | 무겁다(수백 회 시뮬) — 종합 감사 전용 |
| `_audit_roundtrip.py` | offscreen Qt 로 실제 기동 — **모듈 분할 후 유일한 기동 검증** | 워커 실행 경로는 안 지난다 |
| GUI 스모크(pywinauto/UIA) | exe 전용 버그 — 워커 경로·시그널·리소스 경로 | 시각적 깨짐 · 안 눌러본 경로 |
